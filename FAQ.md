# Frequently Asked Questions: Express Session Auth & User Portal

### 1. What is Express Session Auth & User Portal?
Stateless and session-based authentication microservice with password salting and CSRF guards.

### 2. What technology stack does it use?
Built with Node.js (Express, Session Management, Bcrypt), Vanilla JS.

### 3. Where is this project deployed?
Hosted live at: https://aj-login-auth-portal.onrender.com/health

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
